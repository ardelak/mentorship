THE 4 ESSENTIAL GIT COMMANDS

1. git status — Inspect changes in your repository.
2. git add . — Stage all altered files for the next checkpoint.
3. git commit -m "..." — Save staged snapshot with a descriptive message.
4. git push — Upload local commits to remote GitHub servers.

Terminal — First Push Workflow
$ git init
$ git add .
$ git commit -m "feat: initial commit of profile generator"
$ git branch -M main
$ git remote add origin https://github.com/levani/python-journal.git
$ git push -u origin main

character.py
class Character:
    def __init__(self, name, health=100):
        self.name = name
        self.health = health

    def take_damage(self, amount):
        self.health -= amount
        print(f"{self.name} took {amount} damage! Health: {self.health}")

    def __str__(self):
        return f"Character: {self.name} | HP: {self.health}/100"
AHA! MOMENT

Replacing cryptic memory addresses like <__main__.Player object at 0x...> with clean, automatically formatted string outputs simply by defining __str__!

COMMON TRACEBACK CATALOG

• NameError: Variable name misspelled or accessed before assignment.
• TypeError: Operation performed on incompatible types (e.g., "10" + 5).
• AttributeError: Trying to access a method/variable that doesn't exist on an object.
• IndexError: Attempting to access a list position outside its valid bounds.

THE "EXPLAIN, DON'T FIX" PROMPT TEMPLATE

"I am getting this Python error in my CLI application: [Paste Traceback Error]. Explain why this happened and give me a step-by-step hint on how to fix it, but do not write the full code solution for me."
