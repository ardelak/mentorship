Personalized Mentorship Program:
Applied Computer Science & Software Development
Student: Levani
Timeline: September 2026 – May 2027
Format: 1 hour/week, 1-on-1 online sessions
Core Objective: Transition from academic computer science (IGCSE) to practical software engineering,
culminating in the ability to build independent, portfolio-ready projects.
Block 1: The Developer’s Toolkit & Python Mastery (September – October)
Focus: Moving from academic code to real-world development environments. Since Levani already has a
foundation in Python syntax and basic algorithms from his IGCSE prep, this block focuses on professional
tools and advanced programming paradigms.
Key Topics:
● Setting up a professional local environment (VS Code, terminal basics, virtual environments).
● Version Control: Introduction to Git (commit, push, pull, branch) and GitHub.
● Advanced Python: Object-Oriented Programming (OOP) concepts (Classes, Objects, Inheritance)
to write scalable code.
● AI Integration: Introduction to using AI tools (like GitHub Copilot or ChatGPT) as a coding
assistant—focusing on prompt engineering, code review, and understanding AI-generated code
rather than blind copy-pasting.
Practical Application: Writing code locally and pushing it to a remote GitHub repository.
Mini-Project: Advanced CLI Task Manager — A command-line application using OOP and File Handling
(building on his summer knowledge) that allows users to add, delete, and categorize tasks, with all code
version-controlled on GitHub.
Block 2: Connecting to the World – APIs & Data Handling (November –
December)
Focus: Interacting with external services and working with real-world data formats. This block expands
Levani's understanding of data beyond local file handling (which he covered in July with his tutor) into the
realm of web data.
Key Topics:
● Understanding the Client-Server model and HTTP requests (GET, POST).
● Working with JSON data.
● Using Python’s requests library to interact with external REST APIs.
● Reading API documentation and generating API keys.
Practical Application: Parsing large amounts of external data and extracting useful information.
Mini-Project: Live Data Tracker — A Python app that connects to a public API (e.g., OpenWeatherMap,
NASA, or a Currency Exchange API) to fetch, process, and display live data based on user input.
Block 3: Data Persistence & Introduction to Databases (January – February)
Focus: Moving from simple .txt files to structured database management.
Key Topics:
● Relational databases vs. flat files.
● Introduction to SQL (Select, Insert, Update, Delete).
● Using SQLite with Python (via sqlite3 or an ORM like SQLAlchemy).
● Designing simple database schemas for applications.
Practical Application: Writing SQL queries and connecting a Python script to a database securely.
Mini-Project: Personal Finance Tracker / Library System — Upgrading a previous script to store data in a
SQL database instead of text files, ensuring data isn't lost and can be searched efficiently.
Block 4: Full-Stack Basics & Software Architecture (March – April)
Focus: Understanding how modern software products are built and distributed. Introducing web
technologies to give Levani a visual output for his Python logic.
Key Topics:
● Introduction to Frontend basics: HTML, CSS, and an introduction to JavaScript.
● Introduction to Backend basics: Setting up a simple local server using Python (Flask or FastAPI).
● Connecting the backend logic and database to a frontend interface.
● Understanding modern software product architecture.
Practical Application: Turning a local Python script into a locally hosted web application.
● Mini-Project: A simple, interactive Web Application (e.g., a personal portfolio site with a functional
contact form, or a dynamic To-Do list accessible via a web browser).
Block 5: Capstone Project & Portfolio Strategy (May)
Focus: Independent development and project scaling. The final month is dedicated to simulating a
real-world project lifecycle, synthesizing all the skills learned throughout the year.
Key Topics:
● Ideation and technical scoping for a portfolio-level project.
● Agile basics: breaking a large project into weekly manageable tasks.
● Debugging complex systems and refactoring code.
● Deploying a project to the web (using free tiers like GitHub Pages, Render, or Heroku).
Final Capstone Project: A comprehensive software project chosen by Levani (e.g., a Telegram/Discord
bot that scrapes web data, a web app for a school club, or a basic text-based RPG game with a database).
This project will serve as the first major piece for his future US University portfolio.
Mentorship Approach & Synergy with IGCSE:
● No Overlap: Levani’s academic tutor covers IGCSE Paper 2 (pseudocode, trace tables, error
detection theory). This mentorship will strictly focus on applied engineering (Git, Web, APIs, OOP,
Databases), ensuring he gets a highly practical, portfolio-driven experience.
● Homework: Given the 1-hour/week format, sessions will be highly interactive (pair programming,
architecture discussions, code reviews). Levani will be expected to write code and push to GitHub
between sessions (approx. 1.5 - 2 hours of independent practice per week).
● Adaptability: The speed of transitioning from Python to JavaScript (Block 4) will depend entirely on
Levani's comfort level. If he needs more time mastering backend Python, we can scale down the JS
frontend work and utilize template engines instead.
