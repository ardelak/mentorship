1 Part 1 · The Danger Zone

The Anatomy of API Security

Why hardcoding API keys is the fastest way to compromise your developer account.

TERMINOLOGY

Endpoint: A specific URL where an API can be accessed to perform a specific function (e.g., https://api.example.com/users).

Hardcoding: Embedding data directly into the source code of a program instead of obtaining it from an external source (like a file or environment variable). Hardcoding secrets is a major security risk.

Until now, we used completely open endpoints. Real-world services like NASA, OpenAI, or financial databases require an API Key — a unique password that tracks your usage and billing.

The Rookie Mistake (DO NOT DO THIS)
import requests

# ❌ HARDCODED SECRET! If you push this to GitHub, bots will scrape
# your key in less than 3 seconds and abuse your account.
API_KEY = "live_589345y3498hg3498gh3489hg"
url = f"https://api.nasa.gov/planetary/apod?api_key={API_KEY}"

response = requests.get(url)
THE GITHUB BOT THREAT

Automated scripts constantly scan public GitHub repositories for patterns matching AWS keys, Stripe tokens, and generic API keys. A leaked key can result in thousands of dollars in unauthorized usage charges before you even realize you made a mistake.

How to pass a key securely?

Instead of putting the key in the URL (where it gets saved in server logs), professional APIs often prefer you pass the key hidden in the HTTP Headers.

Free vs. Paid APIs

APIs generally fall into different tiers depending on usage limits and data value.

  • Free/Open APIs: Do not require an API key or offer generous free tiers for personal use.
    • Open-Meteo: Free weather forecast API without keys.
    • PokéAPI: Free RESTful Pokémon API.
  • Freemium APIs: Require a key and offer a limited free tier, charging for higher usage.
    • NASA APIs: Free API key required for higher rate limits.
    • RAWG Video Games Database: API key required, free tier available.
    • OpenWeatherMap: API key required, 1,000 free API calls per day.
  • Paid APIs: Strictly charge per request or require a monthly subscription.
    • OpenAI API: Pay-as-you-go billing model based on token usage.
    • AWS APIs (Various): Typically follow a usage-based pricing model.
2 Part 2 · The Professional Solution

Environment Variables & .env

Keep your code public, but your secrets local.

The standard industry practice is to store credentials in a special file called .env on your local computer, and tell Git to completely ignore it using a .gitignore file.

Terminal Installation
$ pip install python-dotenv requests

Create these three files in your project folder:

3 Part 3 · Architecture

The OOP API Client

Combine Object-Oriented Programming with network requests.

Instead of passing the API key into every single requests.get() call you make, we can create an OOP Client using requests.Session(). The session remembers your authentication headers automatically!

api_client.py
import requests

class AuthenticatedApiClient:
    def __init__(self, api_key):
        self.base_url = "https://api.example.com/v1"
        
        # A Session object persists settings across all requests
        self.session = requests.Session()
        
        # We attach the key to the headers ONCE upon initialization.
        # Many APIs use the "Bearer" token standard.
        self.session.headers.update({
            "Authorization": f"Bearer {api_key}",
            "Accept": "application/json"
        })

    def get_game_details(self, game_id):
        # We don't need to pass the key here anymore! The session handles it.
        endpoint = f"{self.base_url}/games/{game_id}"
        
        try:
            response = self.session.get(endpoint, timeout=10)
            response.raise_for_status()
            return response.json()
        except requests.RequestException as e:
            print(f"❌ Network Error: {e}")
            return None
AHA! MOMENT

By wrapping the API inside a Python class, your main CLI menu never has to worry about HTTP status codes, headers, or URLs. It just calls client.get_game_details(45) and gets a clean Python dictionary back.

Drill 2: Spot the Security Flaw

Look at the code below. Even though the developer used os.getenv(), there is a massive security flaw. What is it?

flawed_app.py
import os
import requests

api_key = os.getenv("SECRET_API_KEY")
url = f"https://api.secure-data.com/v1/users"

try:
    res = requests.get(url, headers={"X-Api-Key": api_key})
    res.raise_for_status()
except requests.RequestException as e:
    # WHAT'S WRONG HERE?
    print(f"Error accessing {url} with key {api_key}. Error: {e}")
ANSWER

If the API call fails, the program prints the actual secret key to the console logs! If this was running on a cloud server, those logs are often stored and visible to third-party monitoring tools. Never log credentials!
