2 Lesson 2 · 60 Minutes

Your Code Time Machine — Git & GitHub Basics

Objective: Understand Git as a "save point" system for code, make local commits, and push a project to a private GitHub repository.

THE 4 ESSENTIAL GIT COMMANDS

1. git status — Inspect changes in your repository.
2. git add . — Stage all altered files for the next checkpoint.
3. git commit -m "..." — Save staged snapshot with a descriptive message.
4. git push — Upload local commits to remote GitHub servers.

Terminal — First Push Workflow
$ git init
$ git add .
$ git commit -m "feat: initial commit of profile generator"
$ git branch -M main
$ git remote add origin https://github.com/levani/python-journal.git
$ git push -u origin main
AHA! MOMENT

Refreshing the GitHub web page in a browser and seeing local code and commit history appear online instantly!

3 Lesson 3 · 60 Minutes

Thinking in Objects (Part 1) — The Blueprint & Attributes

Objective: Understand why procedural variables become messy and learn how to create custom object blueprints using Python class and __init__().

player.py
class Player:
    def __init__(self, name, score):
        self.name = name
        self.score = score

# Instantiating two distinct objects
player1 = Player("Levani", 100)
player2 = Player("Alexey", 85)

print(player1.name)   # Dot notation access -> "Levani"
print(player2.score)  # Dot notation access -> 85
AHA! MOMENT

Realizing that a single class blueprint can spawn dozens of unique object instances, each holding its own state and data!

4 Lesson 4 · 60 Minutes

Thinking in Objects (Part 2) — Methods & Changing State

Objective: Add actions (methods) to classes, modify object state dynamically, and use __str__ for friendly print outputs.

character.py
class Character:
    def __init__(self, name, health=100):
        self.name = name
        self.health = health

    def take_damage(self, amount):
        self.health -= amount
        print(f"{self.name} took {amount} damage! Health: {self.health}")

    def __str__(self):
        return f"Character: {self.name} | HP: {self.health}/100"
AHA! MOMENT

Replacing cryptic memory addresses like <__main__.Player object at 0x...> with clean, automatically formatted string outputs simply by defining __str__!

5 Lesson 5 · 60 Minutes

Lists of Objects & Simple Data Files

Objective: Store multiple custom objects inside Python lists, iterate over them with loops, and save/load data using .json files.

manager.py
import json

# Iterating over a list of custom objects
pet_list = [Pet("Rex"), Pet("Milo")]
for pet in pet_list:
    pet.feed()

# Saving object data to JSON
raw_data = [{"name": p.name, "hunger": p.hunger} for p in pet_list]
with open("data.json", "w") as f:
    json.dump(raw_data, f, indent=2)
FIELD NOTE

JSON (JavaScript Object Notation) is the universal format for storing and transferring structured data across modern apps and APIs.

6 Lesson 6 · 60 Minutes

Decoding Errors & AI as Your Coding Partner

Objective: Demystify terminal error messages (Tracebacks) and learn how to use AI tools as debugging assistants without copy-pasting blindly.

COMMON TRACEBACK CATALOG

• NameError: Variable name misspelled or accessed before assignment.
• TypeError: Operation performed on incompatible types (e.g., "10" + 5).
• AttributeError: Trying to access a method/variable that doesn't exist on an object.
• IndexError: Attempting to access a list position outside its valid bounds.

THE "EXPLAIN, DON'T FIX" PROMPT TEMPLATE

"I am getting this Python error in my CLI application: [Paste Traceback Error]. Explain why this happened and give me a step-by-step hint on how to fix it, but do not write the full code solution for me."
