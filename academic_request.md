Ментор по Computer Science / программированию для долгосрочной индивидуальной работы с нашим студентом в период с сентября по май.

Студент живёт в Грузии, обучение и коммуникация с ним проходят на английском языке. Примерно через два года он начнёт поступление в университеты США на программы Computer Science. При этом сейчас мы видим, что для дальнейшей реализации сильных проектов и формирования конкурентного портфолио ему в первую очередь необходимо усилить именно hard skills — практические навыки программирования и владение основными инструментами Computer Science.

По основной международной школьной программе у студента уже есть отдельный тьютор, поэтому здесь мы ищем не академического преподавателя школьной программы, а именно практико-ориентированного ментора по программированию.

Хотели бы выстроить программу примерно по логике хорошего курса программирования, но индивидуально под уровень и прогресс студента. В неё могут входить:
- изучение одного или нескольких языков программирования, в первую очередь Python, а далее при необходимости JavaScript / Java / C++ или других релевантных языков;
- основы алгоритмов, структур данных и логики программирования;
работа с Git и GitHub;
- основы работы с API, базами данных и внешними сервисами;
- знакомство с frontend / backend и принципами устройства современных software-продуктов;
- работа с AI-инструментами для программирования с обязательным пониманием и разбором созданного кода;
- регулярные практические задания;
- создание небольших проектов по завершении отдельных тематических блоков;
- постепенный переход от учебных задач к самостоятельной разработке более комплексных программ и приложений.

Для нас важно, чтобы обучение было максимально практическим: студент не просто изучал синтаксис языка, а постоянно применял новые навыки — писал программы, решал задачи, разбирал ошибки, работал с реальными инструментами разработчика и собирал небольшие проекты.

Итоговая цель программы — к концу учебного года сформировать у студента достаточно сильную техническую базу, чтобы в дальнейшем он мог самостоятельно или вместе с профильным ментором переходить к реализации более серьёзных Computer Science / software-проектов для университетского портфолио.

Формат работы — онлайн, индивидуальные занятия на английском языке.
